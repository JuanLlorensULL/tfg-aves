\chapter{Código fuente y recursos}
\label{ch:codigo}

El código desarrollado en este trabajo está disponible en el repositorio:

\begin{center}
  \url{https://github.com/JuanLlorensULL/tfg-aves}
\end{center}

La etiqueta \texttt{v0.5-o5-completo} señala el estado del repositorio
en el momento de la defensa.

\section*{Instalación}

El entorno requiere Python~3.12.3 y el gestor \texttt{uv}.
Con el repositorio clonado:

\begin{verbatim}
uv sync            # instalar dependencias
uv run pytest -q   # ejecutar los tests
uv run jupyter lab # abrir los cuadernos
\end{verbatim}

\section*{Datos}

El fichero en bruto (\texttt{data/raw/migration\_original.csv},
$\approx$21~MB) no está versionado; se obtiene de Movebank
\cite{movebank_gulls}. Los datos procesados (\texttt{data/processed/})
sí están incluidos en el repositorio.

\section*{Estructura}

\begin{description}
  \item[\texttt{src/tfg\_aves/}] Paquete Python: módulos de preparación
    de datos, cadenas de Markov, HMM, aprendizaje automático y visualización.
  \item[\texttt{notebooks/}] Cuadernos de exploración en formato Jupytext.
  \item[\texttt{reports/}] Figuras, tablas y texto de la memoria.
  \item[\texttt{tests/}] Suite de tests con pytest.
  \item[\texttt{data/}] Datos intermedios y procesados.
\end{description}
